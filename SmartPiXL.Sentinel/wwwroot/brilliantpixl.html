How to Read This Dashboard

Real Visitor vs Bot
Every page load is checked two ways: first against a database of ~4,000 known bot user-agent strings, then scored 0–100 on behavioral patterns. Score below 30 with no bot match = real person.
Lead Score
A 0–100 quality rating for each real visitor. Factors: time spent on site, pages viewed, mouse activity, device quality, and location relevance. 70+ is a strong lead.
Data Signals
The fingerprint script collects device characteristics — screen size, graphics card, audio processing, etc. Each signal helps distinguish unique devices. More signals = more accurate identification.
Privacy Tools
Some visitors use tools that block or spoof device data. We detect these via inconsistencies in reported vs actual capabilities. Not always malicious — some are privacy-conscious users.
Dwell Time
How long a visitor stayed on a page before navigating away or closing the tab. Measured in seconds.
